# pets-food
1.问题描述
1.1行业背景
近年来，随着居民可支配收入的提升以及“宠物拟人化”趋势的增强，人们对于宠物的需求增加，中国宠物经济持续高速发展，宠物食品作为核心细分赛道，呈现出显著的结构性升级特征。《2024年中国宠物行业白皮书》中指出“随着宠物家庭化趋势加深，宠物主的喂养理念正从满足基本生存需求向精细化、健康化升级”，意味着当前宠物主对食品的关注重点已从“吃饱”转向“吃好”，推动市场向高端化、功能化、精细化方向演进。
 
图1.1《2024年中国宠物行业白皮书》统计消费市场规模
在产品形态方面，近年来宠物食品种类逐渐增多，据《2024年中国宠物行业白皮书》统计，干粮、膨化粮干粮类等仍占据主导地位，而湿粮因含水量高、适口性好、更贴近宠物天然饮食结构等优势获得市场认可，但其市场份额也受到干粮挤压，对比2023年有所下降。2024年湿粮的整体购买率相较于2023年增长速度小于下降速度，表明其市场渗透尚处于早期阶段，存在较大的市场开发空间和增长潜力。对于中高端品牌而言，湿粮不仅是产品线延伸的重要抓手，更是提升用户粘性、增强品牌差异化竞争力的关键载体。
同时，由《2024年中国宠物行业白皮书》统计，犬类宠物食品中主食食品类中，干粮、湿粮、烘焙粮等比例相较于2023年有幅度上升，而其他主粮类别比例均有幅度下降，某种程度上表明了宠物主对于狗狗粮食的消费趋势向干、湿、烘焙粮移动。说明干粮与湿粮具有一定的研究价值。
 
图1.2《2024年中国宠物行业白皮书》统计购买主粮品类
本项目聚焦商务情境为作为一家宠物公司的线上零售渠道，主要零售宠物的食品，包括干粮、湿粮、零食等，现在由于行业竞争激烈，公司需要对他的干、湿粮食品产品进行重新规划，公司需要对线上干粮湿粮收集到的相关数据进行分析，获得主粮干湿粮食品的营销建议，采取营销手段让更多的消费者为公司产品买单。在此背景下，公司需要基于历史交易与用户行为数据，深入挖掘消费者偏好与购买动因，为主粮宠物食品产品的精准营销、用户触达及订阅服务优化提供数据驱动的决策支持和优化策略。
1.2数据来源
在数据科学分享平台Kaggle上，我们可以围绕“宠物食品”（petfood）这一核心主题，通过其强大的数据集搜索功能，查找相关的公开数据资源。具体操作是，在Kaggle网站的数据集栏目中，使用“petfood”、“petnutrition”、“dogfood”、“catfood”以及“customerorders”等关键词进行检索。这样做的目的是筛选出那些包含消费者购买记录、产品信息以及可能关联宠物特征的数据集。经过筛选与评估，成功地定位并获取了一个目标数据集，即实验所用数据集pet_food_customer_orders。该数据集包含客户标识（customer_id）、宠物标识（pet_id）、订单序列（pet_order_number）与湿粮订单计数（wet_food_order_number）；订阅状态（pet_has_active_subscription）与食品等级（pet_food_tier）；宠物特征如注册时间（pet_signup_datetime）、过敏源（pet_allergen_list）、健康问题（pet_health_issue_list）、绝育状态（neutered）、性别（gender）、体型（pet_breed_size）及生命周期阶段（pet_life_stage_at_order）；购买行为数据如订单日期（order_payment_date）、干粮与湿粮卡路里（kibble_kcal,wet_kcal）及总热量（total_order_kcal）；促销与互动信息如折扣（wet_food_discount_percent）、网站会话（total_web_sessions）、在线时长（total_minutes_on_website）以及客服记录（last_customer_support_ticket_date）等字段。为深入分析干湿粮消费差异、用户留存及产品偏好提供了完整的数据基础，也为后续深入分析宠物主的消费行为、产品偏好以及干粮与湿粮的市场表现对比提供了扎实的数据基础。
 
1.3问题描述
1.3.1宠物食品本身比较
根据宠物摄入粮食的卡路里量，分析和比较干粮和湿粮的区别与联系。分析湿粮本身的质地会对订单产生什么影响。
同时厘清干粮与湿粮的消费关系。我们将首先计算“纯干粮”、“纯湿粮”及“混合”订单在总订单中的比例，以观察市场基本格局。然后，通过计算同一订单或同一宠物历史订单中干粮热量与湿粮热量之间的相关系数，判断其关系本质。若二者呈现显著负相关，则表明用户倾向于在两者间进行取舍，存在替代关系；若呈现显著正相关，则表明用户倾向于同时购买或增加一种的同时也增加另一种，存在互补关系。
1.3.2消费者分析
深入探究宠物食品消费模式，识别影响宠物食品购买决策（特别是干粮与湿粮选择）的关键消费者与宠物特征。哪些消费者或者拥有那些宠物特征的消费者购买petfood的比例数量如何，其中哪些消费者或者拥有哪些宠物特征的消费者湿粮的比例数量如何。对用户与宠物画像对比分析。我们将基于客户标识（customer_id）和宠物标识（pet_id），对购买“纯干粮”、“纯湿粮”以及“混合”订单的用户群体进行画像对比。重点比较的宠物特征包括：宠物体型（pet_breed_size）、性别（gender）、绝育状态（neutered）、生命阶段（pet_life_stage_at_order）等关键字段。通过统计分析各组人群的比例与特征分布，揭示不同类型消费者的偏好差异。
1.3.3平台用户分析
识别湿粮采纳的可干预杠杆点。重点分析促销活动、客服互动及订阅状态等平台可主动运营的变量，对用户初次及持续购买湿粮决策的影响。具体而言，将探究湿粮折扣（wet_food_discount_percent）的力度与湿粮订单量（wet_food_order_number）之间的关系，评估促销效率；分析客服互动记录（last_customer_support_ticket_date，ustomer_support_ticket_category）是否与湿粮采纳存在关联，识别有价值的服务触点；并比较订阅用户（pet_has_active_subscription）与非订阅用户在湿粮消费模式上的差异，探索订阅制对培养湿粮消费习惯的潜在作用。此阶段旨在识别出能够有效推动湿粮试用的关键运营手段。
诊断平台用户流失状况并制定留存策略。在理解消费驱动因素的基础上，我们将评估平台的整体健康度。通过计算历史用户流失率（流失用户数/总用户数），并使用生存分析绘制用户留存周期，来量化流失问题的严重性与时间规律。进而，我们将深入探究导致流失的多元因素，并利用预测模型识别高流失风险用户特征。最终，综合两阶段分析，试图提出一套整合的、数据驱动的客户留存与价值提升方案来提高用户购买率。
1.4研究意义
本研究聚焦于线上犬类宠物干湿粮消费行为，具有重要的理论价值与实践意义。在理论层面，研究通过整合描述性统计、推断统计，如卡方检验、Mann-WhitneyU检验等、机器学习如逻辑回归、随机森林、K-means聚类等及生存分析等多种方法，构建一个从“产品—消费者—平台”三位一体的系统性分析框架，不仅深化了对非正态分布下宠物食品消费偏好的理解，也为电子商务环境下用户行为与留存研究提供了可复用的方法论范式。
在实践层面，研究结论直击当前宠物食品电商运营中的核心痛点，干粮虽为主流但增长趋稳，湿粮潜力巨大却渗透不足，用户整体流失率高企。本研究旨在精准识别出影响湿粮采纳的关键杠杆点和驱动用户留存的核心因素，同时揭示了过度依赖价格促销的负面效应。这些洞察为企业优化产品结构、实施精准营销和构建长效留存机制提供了坚实的数据支撑与明确的行动方向。最终，研究成果有助于企业实现从“流量获取”向“用户价值深耕”的战略转型，在激烈的市场竞争中构建以科学喂养、精细化运营和长期客户关系为核心的可持续竞争优势。
1.5研究方法
1.5.1宠物主粮食品分析
围绕“干湿粮卡路里差异与质地影响”、“二者消费关系（替代/互补）”两部分展开，对数据进行清洗与重构：订单类型，根据kibble_kcal和wet_kcal将每个订单标记为“纯干粮”、“纯湿粮”或“混合”。宠物/用户级聚合，按pet_id或customer_id聚合，计算其历史总干粮热量、总湿粮热量、平均湿粮比例、购买频率等。质地变量，从wet_food_textures_in_order中提取分类变量，用于后续分析。
接着进行描述性统计，分析干湿粮卡路里，对kibble_kcal和wet_kcal进行描述性统计（均值、中位数、分布），并使用箱线图或密度图进行可视化比较。通过独立样本t检验或Mann-WhitneyU检验判断二者卡路里均值差异是否显著。同时统计各湿粮质地的订单频率。更进一步，可以构建逻辑回归模型，以“是否购买湿粮”为因变量，以质地类型、宠物特征等为自变量，量化不同质地对湿粮购买概率的影响。
最后，计算“干粮”“纯湿粮”、“混合”订单在总订单数及总用户数中的比例，并使用条形图展示。在“混合”订单的子集中，计算kibble_kcal与wet_kcal的皮尔逊相关系数；在聚合后的数据上，计算每个宠物历史总kibble_kcal与总wet_kcal的相关系数，对最后的结果进行解读。
综上，整个研究思路通过结合统计检验、相关性分析和回归建模，全面回答干湿粮的差异、相互关系，为商业决策提供数据支持。
1.5.2消费者分析
深入探究宠物食品消费模式，围绕识别影响宠物食品购买决策的关键消费者与宠物特征。基于客户标识（customer_id）和宠物标识（pet_id），对购买“纯干粮”、“纯湿粮”以及“混合”订单的用户群体进行画像对比，重点比较宠物体型、性别、绝育状态、生命阶段等关键特征，揭示不同类型消费者的偏好差异。
（1）首先对原始数据进行清洗和转换，包括处理缺失值、异常值检测、变量类型转换等。构建关键分析变量：根据订单中的干粮卡路里（kibble_kcal）和湿粮卡路里（wet_kcal）数值，将每个订单划分为三类消费类型，纯干粮订单：wet_kcal=0且kibble_kcal>0；纯湿粮订单：wet_kcal>0且kibble_kcal=0；混合订单：wet_kcal>0且kibble_kcal>0。同时计算湿粮消费比例（wet_kcal/total_order_kcal）作为连续型分析变量。此外，将分类变量如宠物体型、性别、绝育状态等转换为因子类型，时间变量转换为日期类型，为后续分析做好准备。
（2）对三类消费群体进行全面的描述性统计分析。计算三类订单的数量分布、比例关系，分析整体消费模式特征；分别统计三类群体在宠物体型、性别、绝育状态、生命阶段、食品等级、健康问题、口味偏好等特征上的频数分布与比例差异；比较三类群体在网站访问行为、订阅状态、折扣使用、客户服务互动等方面的行为差异，通过条形图、堆叠条形图、热力图等可视化手段直观展示各类特征的分布差异。
（3）运用统计检验方法探究特征差异的显著性。运用卡方检验，检验三类消费群体在分类特征（如体型、性别、绝育状态等）上的分布是否存在显著差异；运用方差分析，比较三类群体在连续变量（如湿粮比例、网站停留时间等）上的均值差异；运用比例检验分析特定特征群体（如大型犬、有健康问题的宠物）在三类消费模式中的比例是否显著不同。
（4）建立逻辑回归模型识别影响消费决策的关键因素，以是否购买湿粮（二元变量）为因变量，以宠物特征和消费者行为特征为自变量，识别显著影响湿粮购买决策的因素。
（5）时间演变与行为模式分析，从动态角度分析消费模式的变化，按时间序列分析同一宠物的消费模式变化轨迹，识别从干粮向湿粮或混合粮转变的关键时点；分析网站访问行为、客户服务互动等时间序列特征与购买决策的时间关联性；研究首次购买湿粮后的消费行为变化特征。
（6）基于分析结果构建完整的用户画像。运用K-means聚类方法，基于宠物特征和消费行为对用户进行市场细分，并系统描述消费群体的典型特征，形成完整的用户画像。
通过以上系统分析，全面揭示影响宠物食品消费决策的关键因素，为精准营销和产品优化提供数据支持。
1.5.3平台用户分析
聚焦宠物食品电商平台用户留存问题，通过生存分析方法深入探究影响用户流失的关键因素。通过识别平台可干预的运营杠杆点，特别是湿粮采纳、订阅制度、客服互动等可控变量对用户留存的影响，构建用户流失预测模型，诊断平台用户流失状况并制定科学有效的留存策略。
首先对原始订单数据进行清洗与重构，包括处理缺失值、异常值检测、变量类型转换等基础工作。重点构建用户级别分析数据集，基于订单历史计算每个宠物的关键行为指标，包括首次/末次订单日期、总订单数、湿粮购买情况、折扣使用情况等。定义用户流失状态，设定90天观察期为判定标准，即用户最后一次订单后90天内无新订单即标记为流失。
接着进行描述性统计分析，通过计算整体流失率、按关键特征分组流失率等指标，初步了解用户流失的总体状况。分析不同用户群体（如订阅与非订阅用户、湿粮购买者与非购买者、有无客服互动用户）在流失率上的差异，为后续深入分析提供方向。
运用Kaplan-Meier方法绘制生存曲线，直观展示不同用户群体的留存随时间变化情况。重点比较三组关键群体：订阅状态（订阅vs非订阅）、湿粮购买行为（曾购买vs从未购买）、客服互动情况（有互动vs无互动）。通过生存曲线对比和log-rank检验，验证这些因素对用户留存的显著性影响。
构建Cox比例风险模型探究多因素对用户流失风险的综合影响。首先是单因素分析，分别评估订阅状态、湿粮购买、客服互动、宠物体型、食品等级、平均折扣、湿粮订单比例等变量对流失风险的独立影响；接着是多因素分析，将单因素分析中显著变量纳入多因素模型，控制变量间的相互影响，识别影响用户留存的净效应。采用AIC准则进行变量选择，构建最优模型，通过C-index评估模型区分度，绘制校准曲线评估预测准确性。
最后，针对用户留存这一时间依赖性结局，绘制多时间点的ROC曲线，评估模型在不同时间点的预测性能。通过ROC曲线下面积（AUC）量化模型的预测能力。应用决策曲线分析方法，评估不同阈值概率下模型的临床实用价值，为制定干预策略提供决策支持。通过计算净收益，识别最佳干预阈值。基于简化Cox模型构建列线图，将复杂的统计模型转化为可视化工具，便于实际应用中个体化预测用户流失风险。列线图可直观展示各影响因素对流失风险的贡献度。
